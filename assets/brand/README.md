# Nenu brand assets

- `nenu-logo-master.png` is the selected full-resolution ImageGen monoline mark based on the
  maintainer's black terrier, reduced to a wink and terminal prompt.
- `nenu-banner.png` is the wide Nenu wordmark for README and social surfaces. It identifies Nenu as
  a Herdr agent workbench for mobile and web.
- `nenu-readme.png` is the compact README/avatar derivative.
- Runtime favicons, the Apple touch icon, and PWA icons live in `web/public/` and derive from the
  same monoline mark.
